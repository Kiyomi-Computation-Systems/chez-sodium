# 1b: the pages, and their self-checks

Builder 1b wrote README.org, `docs/quickstart.md`, `docs/passwords.md`, `docs/tokens.md` and
`docs/finding-libsodium.md`. `test-docs` was written beside them, so each page was checked by
1b's own scripts first. The scripts and what they printed are in [1b/](1b/). Each script was run
from the repository root, in the container (`scripts/guix-env`), but `grep.sh`, which ran on the
host.

- **At the profile:** Guix's libsodium, the container's `CHEZ_SODIUM_LIBRARY`.
- **At the floor:** `CHEZ_SODIUM_LIBRARY=$PWD/build/slice5/prefix-1.0.18/lib/libsodium.so.23`.

## Rerunning

```sh

cp .plans/research/m4-slice-1/1b/*.sps .plans/research/m4-slice-1/1b/*.sh build/m4s1-1b/
scripts/guix-env sh -c 'scheme --libdirs src --program build/m4s1-1b/blocks.sps build/m4s1-1b/progs && sh build/m4s1-1b/programs.sh profile && scheme --libdirs src:. --program build/m4s1-1b/text.sps'

```

For the floor, set `CHEZ_SODIUM_LIBRARY` inside the container's `sh -c`, as above.
