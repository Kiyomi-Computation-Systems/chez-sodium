* chez-sodium

Password hashing, random bytes and fast hashing for Chez Scheme, through
[[https://doc.libsodium.org/][libsodium]]'s C library.

#+begin_quote
✨ *AI Disclosure:* LLMs are used extensively in the planning and development of this project.
#+end_quote

chez-sodium will bind a small part of =libsodium= through Chez's foreign
interface, and load it when your program runs: there will be nothing to
compile. It covers four jobs:

- hash a password with argon2id, check it, and tell when a hash needs
  redoing because its limits were raised;
- make random bytes from the system, for keys and tokens;
- hash bytes fast with BLAKE2b, for storing a long random key without storing
  the key;
- compare two secrets in constant time.

SHA-256 and HMAC-SHA256 come later. Encryption and signatures are not
planned.

** Status

*One verb is built so far.* chez-sodium finds libsodium, checks that it is
new enough, and loads it, and =sodium-version= names the version it loaded.
The four jobs above come next.
[[file:.plans/2026-11-22-chez-sodium-project-brief.md][The brief]] sets out what will be bound, and why. Its names may change before
the first release, and the API may change in any release before 1.0.

** Requirements

CI tests each on Linux at its oldest version, and libsodium at its latest
release too:

- Chez Scheme 10.4.0 or later, built with threads
- libsodium 1.0.18 or later
